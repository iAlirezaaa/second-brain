**Longer public description:**

Second Brain OS is a portable, local-first cognitive workspace that combines long-lived memory, knowledge retrieval, agent workflows, skill reuse and safer experimentation. It uses Python's standard library and portable Markdown/SQLite records by default, with optional local AI models and integration adapters. Every agent action should be planned, visible, evidence-linked and reversible. Features are delivered in verified stages, with privacy and human approval as core constraints.

**Status disclaimer:** Operational foundations and experimental CLI/Twin World modules exist. Semantic graph retrieval, autonomous self-training, fully isolated execution and independently authenticated multi-user agents are future work, not shipped features.
