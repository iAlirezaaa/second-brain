# 00_START_HERE

> صفحه انسان (00-10) | نقطه ورود انسان و ایجنت

اینجا را اول بخوان. راهنمای شروع، نقشه سیستم، پروتکل بوت ایجنت و سند طراحی در این ناحیه‌اند.

`PROJECT_CHARTER.md` متن خود مالک است، نه خلاصهٔ یک ایجنت: هدف، قانون‌های غیرقابل‌نقض
(استقلال از هر نرم‌افزار، جای هر فایل، حافظه، چرخهٔ بهبود) و ترتیب اجرا. اگر یک تسک با
این سند فرق کرد، سند برنده است و اختلاف در `14_CANDIDATES/loop/` ثبت می‌شود.

چه چیزی اینجا نمی‌نشیند: داده، لاگ، تنظیمات ماشین، خروجی پروژه. اینها رجیستری و حالت‌اند و جای دیگری هستند.
