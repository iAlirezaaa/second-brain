## قانون سه‌سؤالی برای جای یک فایل

۱. با چشم می‌خوانی/ویرایش می‌کنی؟ → ۰۰ تا ۱۰.
۲. ماشین می‌نویسد و پاک‌کردنش هیچ دانشی را نمی‌بَرَد؟ → ۱۲ (یا ۱۳ اگر آزمایش است).
۳. ماشین می‌نویسد ولی پاک‌کردنش دانش را می‌بَرَد؟ → فعلاً ۱۲، و باید **promote** شود به ۰۲ یا ۰۳ یا ۰۵ با شناسه و شاهد.

## نوع رابطه‌ها

| کلید | معنا | چه کسی مسدود می‌کند |
|---|---|---|
| `parent_ids` | والد ساختاری؛ چند والد مجاز | ساختار سلسله‌مراتب |
| `depends_on` | پیش‌نیاز | تا آماده نباشد، خروجی «یکپارچه» نیست |
| `integrates_with` | قرارداد رابط، بدون والدیت | فقط وقتی قرارداد موجود باشد |
| `related_ids` | لینک ارجاعی | هیچ |
| `variant_of` | نسخه شخصی/متفاوت یک چیز | هیچ؛ ولی از رجیستری موازی جلوگیری می‌کند |
| `derived_from` / `supersedes` | خط‌خون و جایگزینی | جایگزین‌شده از ایندکس فعال بیرون می‌ماند |
| `uses_model_ids` / `uses_prompt_ids` / `uses_workflow_ids` / `produced_by` | زنجیره تولید یک خروجی | نبودشان یعنی خروجی قابل بازتولید نیست |
| `approved_for_harness_ids` | کدام اسکیل برای کدام هارنس تأیید شده | sync بدون آن کاری نمی‌کند |
| `evidence_paths` | مسیری که ادعا از آن خوانده شده | نبودش در `doctor` هشدار است |

## نام‌گذاری

مسیر و نام فایل‌های رجیستری **ASCII**؛ فارسی در **محتوا**. دلیلش عملی است: Git، Task Scheduler، `gh` و stdout ویندوز روی نام غیر‌ASCII رفتار ناسازگار دارند و v2 روی همین ترک برداشت. یادداشت روایی فارسی می‌تواند نام فارسی داشته باشد، ولی هر فایلی که اسکریپتی می‌خواند نه.

## دسترسی

پیش‌فرض بازیابی: ۰۰ تا ۱۰ و `11_CONTROL`. پیش‌فرض ممنوع: `12_RUNTIME`، `13_LAB`، `14_CANDIDATES`، `15_SYSTEM/generated`، `15_SYSTEM/backups`، و `09_OPERATIONS/clients_metadata_only`. دسترسی از دیده‌شدنِ پوشه استنتاج نمی‌شود؛ `config/system.json` مرجع همین فهرست است و `doctor` آن را با واقعیت روی دیسک مقایسه می‌کند.
