# هدف دائمی پروژه — GOAL (فارسی)

**هدف:** ساخت یک مغز دوم مستقل، قابل‌فهم برای انسان و قابل‌استفاده برای ایجنت؛ سیستمی که اطلاعات گوناگون را دریافت، دسته‌بندی، مرتبط، حفظ و با منبع معتبر بازیابی کند. هم پوشه‌های خود ریپوی GitHub باید مرتب و قابل‌پیمایش باشند، هم جست‌وجوی ماشینی دقیق و سریع باشد. سیستم از تجربه‌های تأییدشده یاد بگیرد و با شواهد واقعی، پیوسته بهتر شود.

**قوانین ثابت:**
- اصول و ایده‌های ویژه پروژه (حافظه، تداعی میان حوزه‌ها/ADHD، مدیریت دانش، ایجنت‌ها، مهارت‌ها، خودبهبودی، شبیه‌سازی و مهندسی بلوغ) حذف یا بی‌اجازه دگرگون نشوند؛ نسخه‌های اولیه در `10_ARCHIVE/foundations/` نگهداری شوند.
- فایل‌های اصلی خوانا و قابل‌انتقال باشند؛ ایندکس، دیتابیس، گراف و مدل‌های هوش مصنوعی قابل‌تعویض و بازسازی باشند. اجرای پایه آفلاین و سبک باقی بماند.
- بلوغ هر زیرسیستم بر پایه حجم واقعی، کیفیت، زمان پاسخ، منابع، هزینه و قابلیت اطمینان سنجیده شود؛ فناوری‌ها فقط وقتی واقعاً بهترند تغییر کنند. عقب‌گرد به گزینه ساده‌تر هم ممکن باشد.
- انسان و ایجنت باید هر دو بتوانند اطلاعات را در پوشه‌های منطقی پیدا کنند؛ روت ریپو فقط شامل ورودی‌ها و فایل‌های ضروری سازگاری بماند.
- هر تغییر مهم در هدف، ایده اصیل، ساختار پوشه، فرمت داده یا معماری **قبل از اجرا** با شرح «از چه → به چه، چرا، اثر، ریسک، جایگزین، بنچمارک و راه بازگشت» برای تأیید صریح انسان ارائه شود.

**حلقه GOAL:** هدف را بخوان → فاصله از هدف را اندازه بگیر → گلوگاه اصلی را پیدا کن → راهکارها را مقایسه کن → پیش از تغییر حساس اجازه بگیر → تغییر محدود و قابل‌بازگشت بده → مستقل تست کن → نتیجه و درس را ثبت کن. اگر مدرک کافی وجود ندارد، بگو «هنوز تأیید نشده».

این هدف دائمی است؛ گزینه `scripts/brain.py start --goal` برای مأموریت‌های محدود زیرمجموعه آن استفاده می‌شود. جزئیات و قرارداد انگلیسی: [GOAL.md](GOAL.md).
