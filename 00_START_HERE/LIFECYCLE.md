# چرخه حیات و ارتقا

## ورودی → دانش
`raw → triaged → linked → verified → promoted → archived`

یک ورودی تا وقتی `verified` نشده، حق ندارد به ویکی برسد. منبع بیرونی (خبر، آموزش، پست) همیشه **داده غیرقابل‌اعتماد** است، نه دستور.

## پروژه
`incubating → active → paused / completed → archived`

وضعیت داخل `project.json` و نام پوشه باید یکی باشد؛ `doctor` اگر نخواند، خطا می‌دهد. جابه‌جایی فیزیکی پوشه آگاهانه انجام می‌شود، نه خودکار.

**کد کجا؟** بیرون از Vault، در مخزن خودش. مانیفست پروژه این را نگه می‌دارد:

```json
"repo": { "path": "E:/Layout/projects/my_show", "remote": "git@github.com:USER/my_show.git", "branch": "main" }
```

**نسخه شخصی؟** با `variant_of` به نسخه اصلی وصل می‌شود و یک پوشه مستقل می‌گیرد؛ رجیستری دوتایی برای مدل‌ها یا اسکیل‌ها ساخته نمی‌شود.

## ادعای بیرونی (خبر، قیمت، محدودیت API)
`rumored → announced → available → deprecated` به‌همراه `source_url`، `observed_at`، `last_verified` و سطح اطمینان. بی‌تاریخ یعنی بی‌اعتبار؛ `doctor` رکورد ازتاریخ‌گذشته را علامت می‌زند.

## اسکیل و ایجنت و مدلِ در حال آموزش

```
13_LAB (EXP)  ->  ارزشیابی با شاهد روی دیسک  ->  14_CANDIDATES (CAND)
              ->  تأیید صریح انسان  ->  11_CONTROL (AGT / SKL، وضعیت approved)
              ->  در صورت افت کیفیت  ->  همان ناحیه، با وضعیت deprecated و `supersedes`؛ نسخه‌ی منجمد در صورت نیاز در ۱۰_ARCHIVE
```

چهار شرط، و هر چهارتا در `promote` چک می‌شوند:
۱. `evaluation.passed` و عدد آن، ۲. `safety_review.passed`، ۳. `evidence_paths` وجود داشته باشد روی دیسک، ۴. `human_approved` با امضای تو.

**خروجی بهتر = فینال.** برای خروجی هنری مسیر کوتاه‌تر است: `14_CANDIDATES/outputs/` → با تأیید تو → `05_WORKS/deliverables/`. زنجیره تولید (`uses_model_ids`، `uses_prompt_ids`، `uses_workflow_ids`، `produced_by`) باید پر بماند، وگرنه «فینال» قابل بازتولید نیست و فقط یک شانسِ ثبت‌شده است.

## حلقه‌ها و مودها
حلقه (`LOP`) چیزی است که در فاصله‌های معین اجرا می‌شود (مثلاً جاروی روزانه اخبار، یا بررسی هفتگی متریک). مود (`MDE`) مجموعه‌ی سیاست و دسترسی یک نوع کاری است (پژوهش / ساخت / بازبینی). هر دو **تعریف**‌اند و در `11_CONTROL` می‌مانند؛ اجرای هر حلقه، یک فایل در `12_RUNTIME/jobs/` است که شناسه رجیستری نمی‌گیرد.

## بایگانی
`10_ARCHIVE` یخ‌زده و فقط‌خواندنی است. چیزی که بایگانی شد ویرایش نمی‌شود؛ جایگزینش رکورد تازه است با `supersedes`. **بایگانی، بکاپ نیست.**
