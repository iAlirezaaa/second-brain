# 05_WORKS

> صفحه انسان (00-10) | پرامپت، workflow، اَسِت و تحویل‌دادنی نهایی

چیزهای بازاستفاده‌شدنی و خروجی‌های نهایی: پرامپت، workflow (ComfyUI، n8n، Remotion، DCC)، مانیفست اَسِت و فایل تحویل‌شده.

فایل حجیم بیرون از اینهاست و اینجا فقط مسیر مرجع، هش و نسخه‌اش ثبت می‌شود. هر تحویل‌دادنی باید زنجیره `uses_model_ids` / `uses_prompt_ids` / `produced_by` را داشته باشد، وگرنه قابل بازتولید نیست. پیشوند: PRM، WFL، AST، DEL.
