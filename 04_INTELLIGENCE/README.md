# 04_INTELLIGENCE

> صفحه انسان (00-10) | اخبار، مدل‌ها و شرکت‌ها در یک مرجع

اتم‌های حقیقت درباره اکوسیستم AI: شرکت، خانواده مدل، نسخه مدل، خبر، بنچمارک، اسنپ‌شات قیمت، مقاله و لایسنس. هر رکورد منبع، تاریخ مشاهده و تاریخ آخرین بررسی را نگه می‌دارد.

خانواده مدل، نسخه مدل، API و رانتایم محلی چهار شیء جدا هستند؛ نام نسخه را جای نام خانواده نگذار. این ناحیه خوراک ویکی است، نه خود ویکی. پیشوند: ORG، MOD، VER، NWS، BMK.
