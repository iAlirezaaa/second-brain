# 01_INBOX

> صفحه انسان (00-10) | صف ورودی خام

هر چیزی که از بیرون می‌آید و هنوز دسته‌بندی نشده اینجا می‌ریزد. خام ماندن در این ناحیه اشکال نیست؛ اشکال آن است که چیزی در ۰۱ بماند و کسی تریاژش کند و فراموش شود.

گردش کار: raw -> triaged -> linked -> verified -> promoted -> archived. فایل خام اینجا شناسه رجیستری نمی‌گیرد؛ بعد از تریاژ است که به یک رکورد با شناسه در ناحیه مقصد تبدیل می‌شود.
