# Interrupted source import

Reproduction: `py -3.10 -m unittest discover -s tests -p test_sources.py`.
Before the change an incomplete record without metadata was silently omitted from the
rebuilt index, and importing it again could overwrite its raw file. Regression tests now
check refusal, preservation of the existing index and preservation of the raw bytes.
