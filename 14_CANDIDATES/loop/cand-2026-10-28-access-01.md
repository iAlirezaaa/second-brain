# Access boundary finding

Reproduction: `py -3.10 -m unittest discover -s tests -p test_access_boundary.py`.
Before the fix, search returned files from `14_CANDIDATES` and
`09_OPERATIONS/clients_metadata_only`, and MCP resources could read unlisted files.
`core.fs_read` also allowed `.env`, credential filenames, Git internals and nested secrets
directories; search indexed Markdown files under secrets directories. The regression tests
cover these paths. This is a tool-level boundary, not an OS access control or a secret scanner;
credentials in ordinary files still require separate handling.
