# 03_PROJECTS

> صفحه انسان (00-10) | پروژه‌ها و ساختارشان

برای هر پروژه یک پوشه با `project.json` و مستندات. وضعیت در مانیفست و نام پوشه باید یکی باشد.

قانون مهم: **کد اینجا نمی‌نشیند.** مانیفست آدرس مخزن کد را می‌دهد (`repo.path`، `repo.remote`، `repo.branch`) و آن مخزن تاریخچه خودش را دارد. زیرپروژه با `parent_ids` وصل می‌شود، نه با تودرتوکردن فولدر. نسخه شخصی یک پروژه با `variant_of` ثبت می‌شود و رجیستری موازی نمی‌سازد. پیشوند شناسه: PRJ.
